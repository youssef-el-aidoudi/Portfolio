# Bottle Quality Detection with AI

AI-based bottle quality detection project using image classification.

## Tech stack
Python, TensorFlow, NumPy

## Overview
This project focuses on bottle quality detection using artificial intelligence and image classification techniques. It covers the full pipeline: dataset loading, model training, evaluation, and utility functions for experimentation.

## Features
- Image dataset loading
- Model configuration
- Training pipeline
- Evaluation pipeline
- Utility functions for data handling
